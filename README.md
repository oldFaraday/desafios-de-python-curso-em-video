## Conteúdo por Módulo

### Mundo 1 - Fundamentos da linguagem
- **Aula 5**: Primeiros comandos, variáveis e tipos
- **Aula 6**: Tipos, primos e Saída de dados
- **Aula 7**: Operadores Aritméticos
- **Aula 8**: Utilizando Módulos
- **Aula 9**: Manipulando Texto
- **Aula 10**: Condições Simples

### Mundo 2 - Condições aninhadas (elif) e loops (for/while)
- **Aula 12**: Condições aninhadas
- **Aula 13**: If, Elif e Else
- **Aula 14**: While (Parte 1)
- **Aula 15**: While (Parte 2)

### Mundo 3 - Estruturas de dados, funções, módulos e pacotes
- **Aula 16**: Tuplas

## Como Executar

```bash
# Execute qualquer desafio diretamente com Python
python "Mundo 1/Aula 5/desafio0.py"

# Ou navegue até a pasta e execute
cd "Mundo 1/Aula 5"
python desafio1.py
```
